# Verified AI Cast 한국 시장용 BM 옵션

이 문서는 제품 전략 초안입니다. 실제 계약, 세무, 권리 처리, 광고 수익 정산은 변호사와 회계 검토가 필요합니다.

## 왜 $2,500 고정 노출을 낮춰야 하는가

홈페이지 첫 화면에서 높은 고정 검수비를 노출하면 초기 구매자의 진입 장벽이 커진다. 특히 AI 출연권 시장은 아직 가격 기준이 형성되는 단계라, 구매자는 먼저 다음을 알고 싶어한다.

- 이 배우가 내 캠페인에 승인 가능성이 있는가
- 공개 범위에 따라 어느 정도 예산이 필요한가
- 성과가 낮으면 손실이 너무 커지지 않는가
- 승인되지 않으면 어떤 비용이 발생하는가

따라서 첫 CTA는 “결제”보다 “사용 목적 입력” 또는 “무료 상담”이 적합하다.

## 참고한 플랫폼 과금 구조

- YouTube 장문 영상은 Watch Page Ads 기준으로 파트너에게 광고 순수익의 55%를 지급한다.
- YouTube Shorts는 광고 수익을 풀링한 뒤 engaged views 비중으로 배분하고, 크리에이터가 배정분의 45%를 가져간다.
- TikTok은 Creator Rewards와 monetization module을 통해 다양한 수익원을 한 곳에서 보여주는 방향으로 운영한다.

참고:

- https://support.google.com/youtube/answer/72902
- https://support.google.com/youtube/answer/12504220
- https://newsroom.tiktok.com/introducing-the-new-creator-rewards-program

## 권장 BM 포트폴리오

### 1. 무료 상담 모델

목적: 초기 문의 장벽 제거.

구조:

- 구매자가 배우, 용도, 채널, 예상 공개 기간을 입력
- 플랫폼이 승인 가능성, 리스크, 추천 BM을 안내
- 실제 검수나 배우 측 검토는 아직 시작하지 않음

수익:

- 직접 과금 없음
- 이후 파일럿/정식 검수로 전환

적합 대상:

- 첫 문의
- 예산 범위 탐색
- 브랜드 캠페인 기획 초기

### 2. 소액 파일럿 모델

목적: 구매자가 낮은 비용으로 승인 가능성을 테스트.

구조:

- 제한된 배우 등급 또는 제한된 결과물 1건
- 내부 시안, 피치덱, 비공개 테스트 중심
- 공개 인증서는 발급하지 않거나 “비공개 검수 기록”만 제공

수익:

- 낮은 선불 검수비
- 정식 공개 승인으로 전환 시 일부 크레딧 처리 가능

적합 대상:

- 스타트업
- 숏폼 제작사
- 브랜드 필름 사전 검토

### 3. 고정 라이선스 모델

목적: 전통적인 광고/콘텐츠 계약에 가까운 예측 가능한 구조.

구조:

- 배우 등급, 사용 지역, 기간, 매체, 독점 여부로 견적
- 승인된 URL과 최종 결과물에 인증서 발급
- 기간 종료 시 갱신 또는 만료

수익:

- 라이선스 수수료 12%-18%
- 구매자 인증/검증 수수료 3%-5%
- 소속사 운영 seat 별도

적합 대상:

- 브랜드 필름
- TV/OTT/OOH를 포함한 캠페인
- 명확한 기간과 매체가 있는 프로젝트

### 4. 조회수 기반 성과형 모델

목적: 구매자의 초기 비용 부담을 낮추고 배우/소속사는 성과 상승분을 공유.

구조:

- 낮은 기본료 + 조회수 구간별 추가 정산
- 인증된 URL 또는 연결된 플랫폼 데이터 기준으로 집계
- 월별 정산 상한선을 두어 구매자 리스크 관리

예시:

| 구간 | 정산 방식 |
| --- | --- |
| 0-100k views | 기본료만 |
| 100k-1m views | 1,000 views당 소액 정산 |
| 1m+ views | 상위 구간 단가 또는 보너스 |

주의:

- 조회수 품질 기준이 필요하다.
- 봇/유료 트래픽/비정상 반복 조회는 제외해야 한다.
- YouTube, Shorts, TikTok, Instagram Reels는 지표 정의가 다르므로 동일 단가로 묶으면 안 된다.

적합 대상:

- 유튜브 공개 영상
- 숏폼 캠페인
- 바이럴 가능성은 있으나 예산 확정이 어려운 프로젝트

### 5. 광고 수익 쉐어 모델

목적: 콘텐츠 자체가 광고 수익을 만드는 경우 배우와 소속사가 upside를 공유.

구조:

- 기본 승인료를 낮게 설정
- YouTube AdSense, 플랫폼 광고 수익, 브랜드 스폰서 수익 중 정의된 항목을 배분
- 플랫폼은 정산 인프라/인증 수수료를 별도로 확보

권장:

- 플랫폼 광고 수익은 “실수령액 기준”으로 정의
- 세금, 플랫폼 수수료, MCN 수수료, 환불/차감 항목을 계약서에 명시

적합 대상:

- 유튜브 시리즈
- AI 배우 출연 웹예능
- 지속 업로드 채널

### 6. 구독형/멤버십 모델

목적: 에이전시와 제작사가 반복적으로 쓰는 운영 도구로 수익화.

구조:

- 소속사: 배우 정책, 검수 큐, 인증서, 정산 리포트 관리
- 제작사: 프로젝트 제출, 인증서 관리, URL 모니터링
- 엔터프라이즈: API 검증, SSO, 대량 인증서, 컴플라이언스 리포트

수익:

- 월 구독료
- 좌석당 과금
- API 호출량 과금

적합 대상:

- 배우 소속사
- 광고대행사
- OTT/스튜디오

## 추천 초기 패키지

### Public Entry

- 무료 상담
- 사용 목적 입력
- 승인 가능성 안내

### Pilot

- 낮은 선불 검수
- 비공개 시안 검토
- 정식 승인 전환 가능

### Certified Release

- 정식 라이선스
- 공개 인증서
- URL allowlist
- 철회/만료 상태 관리

### Performance Release

- 낮은 기본료
- 조회수 또는 광고 수익 기반 정산
- 월별 상한선
- 봇/비정상 트래픽 제외

## 홈페이지 반영 원칙

- 첫 화면 또는 첫 가격 섹션에 고정 고가를 노출하지 않는다.
- “무료 상담”, “파일럿”, “성과형 가능”을 먼저 보여준다.
- 실제 결제 기능이 없는 동안은 “상담 요청”과 “사용 목적 입력”을 CTA로 둔다.
- $2,500 같은 숫자는 내부 콘솔이나 later-stage checkout demo에만 남긴다.
